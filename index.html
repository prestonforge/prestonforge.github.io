ArduVCU — Greenpower racing telemetry & battery management Gold CREST · 78 hrs

A £55 open-source Vehicle Control Unit for Greenpower F24 electric racing — built because commercial telemetry costs £100+ and junior teams drive blind.

  • ESP32-based predictive telemetry: live battery-runtime estimation using Peukert's Law implemented from scratch in C++ — no libraries.
  • O(1) moving-average filter: circular-buffer signal smoothing that tames severe motor EMI without stalling the microprocessor.
  • Software safety interlocks: a hysteresis state machine ("Limp Mode", 21.0V cutoff + 1.5V recovery dead-band) that protects cells and prevents relay chatter.
  • Isolated sensing architecture: 24V traction power stepped down via a 100k/10k divider; galvanically isolated current measurement with an ACS712 Hall-effect sensor.
  • Physics-backed pacing: the 0.05V/min pacing target comes from a first-order lead-acid discharge model (Peukert's Law + internal-resistance sag) — an interactive twin and an auditable Excel model ship with the repo.
  • Engineered enclosure: Fusion 360 design with brass threaded inserts and cable-routing slots for track vibration.
